# all-ML-layers-from-scratch
Building every abstraction layers in ML from scratch without agentic coding. Broadly it has three phases: 

1. **Foundations:** Back-bone of a ML-framework

  * Fundamental building blocks

  * Framework bridge

  * Language architecture

  * Tiney Language model

  * Distributed Runtime


2. **Systems and Optimization:**

  * Framework-level optimizations: Support different backbone

  * Kernel-level explorations

  * Distributed runtime optimizations


3. **Evolution:** 

  * Support complex architectures

  * Test-out everything on Raspberry Pi cluster
